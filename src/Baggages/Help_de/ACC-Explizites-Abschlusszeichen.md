### Explizites Abschlusszeichen

Jede Taste, außer den Ziffern 0-9, kann als Abschlusszeichen definiert werden.

Wird ein Abschlusszeichen definiert, wird erst mit der Eingabe des Abschlusszeichens der eingegebene Code überprüft und die Eingabe entsprechend als gültig oder ungültig gewertet.

Wird kein Abschlusszeichen definiert, wird nach jedem Zeichen geprüft, ob ein gültiger Code vorliegt. Falls ja, gibt es sofort eine Reaktion, falls nein, wird auf das nächste Zeichen gewartet. Erst wenn eine festgelegte Zeit kein Zeichen eingegeben wurde, wird die Eingabe als ungültig gewertet.
